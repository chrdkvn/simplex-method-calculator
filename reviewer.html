WORKED EXAMPLE

Example linear programming model

Maximize: Z = 3x₁ + 5x₂

Subject to:

2x₁ + x₂ ≤ 8

x₁ + 2x₂ ≤ 8

x₁, x₂ ≥ 0

For this model, the optimal point is x₁ = 8/3, x₂ = 8/3, giving Z = 64/3 (approximately 21.33). Use the Solver page to inspect the tableau iterations.
